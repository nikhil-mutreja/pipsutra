# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.
Be considerate, use welcoming language, respect differing viewpoints, accept
constructive criticism, and focus on what is best for the community.

Unacceptable behavior includes harassment, insults, discrimination, personal
attacks, and publishing others' private information without permission.

Project maintainers are responsible for clarifying and enforcing these
standards. This project adopts the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
